Happy path POST /api/orders→ PENDING→ Kafka: order.placed→ stock reserved→ payment approved→ CONFIRMED
Out-of-stock POST /api/orders→ PENDING→ Kafka: order.placed→ insufficient stock→ INVENTORY_FAILED
Payment declined INVENTORY_RESERVED→ payment call fails→ stock released (compensation)→ CANCELLED
